Publicação gratuita no GitHub Pages:
1. Crie uma conta em github.com.
2. Crie um repositório público chamado apnaplantacuritiba.
3. Envie todos estes arquivos preservando a pasta assets.
4. Acesse Settings > Pages.
5. Em Build and deployment, selecione Deploy from a branch.
6. Escolha a branch main e a pasta /(root), depois Save.
7. O endereço será semelhante a: https://SEU-USUARIO.github.io/apnaplantacuritiba/
