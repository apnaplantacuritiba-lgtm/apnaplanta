# Apnaplantacuritiba — site institucional

Site estático em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Publicação
1. Apague ou substitua os arquivos antigos do repositório.
2. Envie todo o conteúdo deste pacote, preservando a pasta `assets`.
3. Em **Configurações > Páginas**, mantenha `principal` e `/(raiz)`.
4. Aguarde a implantação e atualize o navegador com `Command + Shift + R`.
